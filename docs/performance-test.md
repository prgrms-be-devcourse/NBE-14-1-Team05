# 📊 대용량 주문 처리 성능 검증 및 스트레스 테스트 보고서

## 1. 개요
대량의 주문 요청이 동시에 발생하는 상황을 가정하여 주문 생성 기능의 스트레스 테스트를 진행했습니다. 
총 10,000건의 주문 요청을 요청 간격(Inter-request Interval)별로 세분화하여 실행하였으며, 성공/실패율, 평균·최대 응답 시간, TPS(Transaction Per Second)를 종합적으로 측정하여 시스템의 부하 처리 한계점 및 안정성을 검증했습니다.

> ⚠️ **Notice**  
> 본 테스트는 H2 인메모리 DB 기반의 애플리케이션 내부 테스트 코드를 통해 수행되었습니다. 네트워크 I/O 및 실제 운영 DB(MySQL 등) 커넥션이 포함된 외부 HTTP 부하 테스트 결과와는 차이가 발생할 수 있습니다.

* **배치당 요청 수:** 1,000건

## 4. 결과 분석

1. **트랜잭션 신뢰성 검증 (100% Availability):** 모든 테스트 케이스에서 실패율 0% 기록 (10,000/10,000 성공)
2. **최적 처리 구간 산출:** 200ms 간격 구간까지 지연 시간(Latency) 최소화 (평균 33~59ms)
3. **병목 현상 및 Implosion Point 발견:** 0.05초(50ms) 간격에서 최대 처리량(8,110.30 TPS)에 도달하였으나 지연 시간 급증, 10ms 구간에서는 Throttling/Lock 경합으로 인한 TPS 감소 관찰
